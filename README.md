# 🍽️ Zomato Landing Page Clone

A pixel-perfect, responsive frontend clone of the **[Zomato](https://www.zomato.com/)** web application landing page, built using pure **HTML5**, **CSS3**, and **JavaScript**.

---

## 🚀 Live Demo & Deployment

## ✨ Features

- 🌟 **Hero / Navigation Header:**
  - Modern transparent navigation bar with quick links (*Get the App, Investor Relations, Add Restaurant, Login, Sign Up*).
  - Prominent search box with location selector and cuisine/dish search.
- 🍕 **Category Options:**
  - Order Online, Dining, and Nightlife & Clubs cards with interactive hover effects.
- 🏆 **Curated Collections:**
  - Trending food & dining collections with smooth overlay animations and badges.
- 📍 **Popular Localities:**
  - Interactive grid listing popular regions & localities around Delhi NCR with places count.
- 📱 **Mobile App Promotion Section:**
  - Interactive download link requester via Email or SMS.
  - App Store & Google Play download badges.
- 📂 **Interactive Accordions:**
  - Dynamic collapsible accordion sections for exploring nearby cuisines, restaurant chains, and delivery cities.
- 🌐 **Comprehensive Footer:**
  - Language and country dropdowns, social media links, company info, and legal links.
- 📱 **Fully Responsive:**
  - Optimized layout for desktops, tablets, and mobile screens.

---

## 🛠️ Tech Stack

- **HTML5:** Semantic markup structure
- **CSS3:** Flexbox, Grid, custom styling, animations & transitions
- **JavaScript (ES6):** Accordion interactivity & dynamic DOM manipulation
- **Feather Icons & Font Awesome:** Clean icon sets
- **Google Fonts:** Clean modern typography

## 💻 How to Run Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/rahulprakash0898/Zomato.git
   ```

2. **Navigate into the directory:**
   ```bash
   cd Zomato
   ```

3. **Open the project:**
   - Simply double click `index.html` to open it in any web browser, **OR**
   - Use VS Code extension **Live Server** (`Right click on index.html -> Open with Live Server`).
